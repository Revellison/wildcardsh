# wildcardsh

Этот скрипт автоматизирует процесс получения Wildcard-сертификата Let's Encrypt (`*.example.com` и `example.com`) с использованием легковесного клиента `acme.sh` и DNS-валидации через API Cloudflare.

## Особенности
* ⚡ **Автоматизация:** Самостоятельно скачивает и устанавливает `acme.sh`.
* ☁️ **Cloudflare DNS-01:** Подтверждает владение доменом через API без необходимости настраивать веб-сервер или открывать порты.
* 🔒 **Безопасность:** Автоматически копирует готовые сертификаты в стандартизированную директорию `/etc/ssl/` и устанавливает правильные права доступа на приватный ключ.
* 🔄 **Автопродление:** `acme.sh` автоматически добавляет задачу в cron для продления сертификатов каждые 60 дней.

## Требования
* Сервер с ОС Linux (с установленной утилитой `curl`).
* Права суперпользователя (`root` или `sudo`) для установки сертификатов в системные директории.
* Домен, управляемый через Cloudflare.
* Cloudflare API Token с правами редактирования DNS (шаблон **Edit zone DNS**).

## Использование

Вам не нужно клонировать репозиторий. Просто выполните следующую команду в терминале вашего сервера, подставив ваши данные:

```bash
curl -sL https://raw.githubusercontent.com/Revellison/wildcardsh/main/setup_wildcard.sh | sudo bash -s -- example.com ВАШ_API_ТОКЕН_CLOUDFLARE
```
